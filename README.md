Desafío de JavaScript: Condiciones y Manipulación del DOM

Este repositorio contiene la solución a tres desafíos prácticos de programación enfocados en el aprendizaje de "condiciones" y "manipulación del DOM" mediante JavaScript, HTML5 y CSS en Visual Studio Code.

---

## Herramientas y Tecnologías Utilizadas

* **HTML5**: Estructuración del contenido semántico en la página.
* **CSS3**: Estilos visuales, diseño responsivo (Flexbox/Viewport) y clases de interacción.
* **JavaScript (ES6+)**: 
  * Captura de elementos del DOM (`document.querySelector`).
  * Manejo de eventos (`addEventListener`).
  * Estructuras condicionales (`if`, `else if`, `else`).
  * Métodos de clases (`classList.add`, `classList.remove`, `classList.contains`).
  * Manipulación de texto e inputs (`textContent`, `value`, `Number()`).
* **Visual Studio Code**: Entorno de desarrollo integrado (IDE).
